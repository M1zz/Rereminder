Rereminder 기능 명세

이 문서는 Rereminder 앱이 현재 제공하는 기능을 정리한 것입니다. 사용자 시나리오, 동작 규칙, 플랫폼별 차이를 함께 기술합니다.


1. 타이머 코어

1.1 기본 동작

사용자는 분 단위와 초 단위로 타이머 시간을 설정할 수 있습니다.
시작 버튼을 누르면 타이머가 카운트다운을 시작하고, 0이 되면 알림과 함께 종료됩니다.
실행 중인 타이머는 일시정지, 재개, 취소가 가능합니다.

1.2 상태 머신

타이머는 다음 다섯 가지 상태를 가집니다.

idle: 시작 전 또는 정지 후 초기 상태
running: 카운트다운 진행 중
paused: 일시정지된 상태
finished: 카운트다운이 0에 도달한 후 정지된 상태 (무료 사용자의 경우)
overtime: 카운트다운이 0을 지나서도 계속 흐르는 상태 (Pro 또는 trial 사용자의 경우)

1.3 백그라운드 동작

앱이 백그라운드로 가거나 종료되어도 타이머는 끝까지 동작합니다. 이를 위해 다음 메커니즘을 사용합니다.

UNUserNotificationCenter 로 종료 시간과 예비 알림 시간을 미리 스케줄
앱이 다시 포그라운드로 돌아오면 endDate 기반으로 남은 시간을 즉시 재계산
앱 그룹 UserDefaults 에 타이머 상태를 영속화하여 cold launch 시 복원

1.4 테스트 모드

설정 화면에서 테스트 모드를 켜면 시간 배수를 조정할 수 있습니다. 5 배속을 선택하면 10 분 타이머가 약 2 분 만에 종료됩니다. 알림 트리거도 동일한 배수로 보정됩니다.


2. 예비 알림 (Pre-alerts)

2.1 동작

본 타이머가 끝나기 전, 사전에 지정한 시점에 미리 알림을 받을 수 있습니다. 예를 들어 10 분 타이머에 5 분, 1 분 예비 알림을 설정하면, 타이머 종료 전에 두 번의 알림을 추가로 받습니다.

2.2 프리셋

기본 프리셋은 30 초, 1 분, 3 분, 5 분, 10 분입니다. 프리셋 토글로 빠르게 추가, 제거할 수 있습니다.

2.3 마커 드래그

타이머 시계 화면 위에 표시되는 예비 알림 마커를 손가락으로 잡고 시계 둘레를 따라 드래그하여 위치를 세밀하게 조정할 수 있습니다.

2.4 무료 한도와 5+5 체험

무료 사용자는 기본적으로 예비 알림 1 개까지 사용할 수 있습니다. 2 개 이상의 예비 알림을 사용하려는 경우 5+5 체험 시스템이 적용됩니다. 자세한 내용은 7번 항목 참조.


3. 발표 모드

3.1 용도

발표나 강연 중 시간 관리를 돕기 위한 모드입니다. 타이머 화면이 발표자 시점에 적합한 큰 글씨와 단순한 레이아웃으로 전환됩니다.

3.2 진입

홈 화면 상단의 모드 선택 (Picker) 에서 Presentation 을 선택하면 진입합니다.

3.3 잠금

발표 모드는 Pro 기능이며 5+5 체험 시스템이 적용됩니다.


4. 오버타임 추적

4.1 동작

타이머가 0 에 도달한 후에도 흐른 시간을 음수가 아닌 양의 카운트로 계속 추적합니다. 발표가 예정 시간을 초과한 경우 얼마나 초과했는지를 시각적으로 보여줍니다.

4.2 잠금

오버타임 추적은 Pro 기능이며 5+5 체험 시스템이 적용됩니다. 무료 사용자가 체험 횟수를 모두 소진하면 타이머는 0 에서 자동 정지하고 finished 상태로 들어갑니다.


5. 타이머 통계

5.1 기록 항목

각 타이머 세션마다 다음을 기록합니다.

날짜와 시각
주 시간 (mainSeconds)
실제 경과 시간 (elapsedSeconds)
완료 여부 (finished)
사용한 예비 알림 목록

5.2 표시 항목

통계 화면에서는 다음을 표시합니다.

전체 세션 수
완료된 세션 수와 완료율
총 사용 시간
평균 사용 시간
최근 사용 기록 목록

5.3 잠금

타이머 통계는 Pro 기능이며 5+5 체험 시스템이 적용됩니다.


6. 타이머 템플릿

6.1 동작

자주 사용하는 타이머 설정 (시간, 예비 알림, 라벨, 색상) 을 템플릿으로 저장하고 재사용할 수 있습니다.

6.2 무료 한도

무료 사용자는 최대 3 개의 템플릿을 저장할 수 있습니다. 4 개째 템플릿을 저장하려고 하면 안내 화면이 표시됩니다. 템플릿은 슬롯 개념이라 5+5 체험 시스템이 적용되지 않고 hard gate 로 동작합니다.


7. 5+5 무료 체험 시스템

7.1 적용 대상

다음 Pro 기능에 적용됩니다.

발표 모드 (presentationMode)
무제한 예비 알림 (unlimitedPrealerts)
오버타임 추적 (overtimeTracking)
타이머 통계 (timerHistory)

다음 기능은 적용되지 않습니다.

무제한 템플릿 (unlimitedTemplates) - slot 개념이라 5+5 모델 부적합

7.2 단계별 동작

기능별로 사용 횟수가 독립적으로 카운트됩니다.

처음 5 회 (count 0 ~ 4): 자유롭게 사용. 화면에 남은 횟수가 표시됨
6 번째 시도 (count == 5): 1 차 안내 화면 표시. 다음 세 옵션 중 선택 가능
  Pro 구매하기
  Try 5 more times 버튼으로 5 회 추가 체험 활성화
  닫고 나중에 결정
6 ~ 10 회 (count 5 ~ 9, 확장 수락 후): 자유롭게 사용
11 번째 시도 (count == 10): 2 차 안내 화면 표시. Pro 구매만 가능

7.3 데이터 저장

각 기능별로 두 가지 값이 UserDefaults 에 저장됩니다.

trial.count.{feature}: Int - 사용 횟수
trial.extension.{feature}: Bool - 1 차 안내 화면에서 확장을 수락했는지 여부

7.4 Pro 사용자

Pro 를 구매한 사용자는 모든 게이트가 .allowed 를 반환하므로 카운터 증가 없이 자유롭게 사용합니다.


8. 결제 및 구독

8.1 상품

단일 일회성 구매 (One-time IAP). 상품 ID 는 com.xa.toki.pro 입니다.

8.2 영속화

구매 상태는 다음 두 곳에 저장됩니다.

Keychain: 앱 삭제 후 재설치에도 유지
UserDefaults: 빠른 조회용 캐시

8.3 구매 검증

StoreKit 의 Transaction.verifications 와 Transaction.currentEntitlements 를 통해 검증합니다. 앱 시작 시 자동으로 entitlements 를 확인하여 구매 상태를 동기화합니다.

8.4 구매 복원

설정 화면에서 Restore Purchases 버튼으로 복원할 수 있습니다. AppStore.sync() 호출 후 entitlements 재검증합니다.


9. 알림 (Live Activity)

9.1 시작

타이머 시작 시 ActivityKit 으로 Live Activity 가 자동으로 시작됩니다. Dynamic Island 와 잠금 화면에 실시간 카운트다운이 표시됩니다.

9.2 실시간 카운트다운

ContentState 에 endDate 를 포함시켜 시스템이 자동으로 카운트다운을 표시하도록 합니다. 1 초 단위로 갱신되며 배터리 소모가 최소화됩니다.

9.3 컨트롤

Live Activity 에 일시정지, 재개 버튼이 표시되어 앱을 열지 않고도 제어 가능합니다.

9.4 종료

타이머가 종료되거나 사용자가 수동으로 정지하면 Live Activity 도 함께 종료됩니다.


10. 위젯

10.1 종류

홈 화면 위젯과 잠금 화면 위젯을 제공합니다.

10.2 표시 정보

타이머가 실행 중일 때는 남은 시간이 표시됩니다.
타이머가 정지 상태일 때는 마지막 설정값 또는 빠른 시작 버튼이 표시됩니다.

10.3 동기화

App Group UserDefaults 와 WidgetCenter.reloadAllTimelines() 로 앱과 위젯이 동기화됩니다.


11. Apple Watch 연동

11.1 독립 실행

Watch 앱은 iPhone 없이도 단독으로 타이머를 사용할 수 있습니다.

11.2 동기화

WatchConnectivityManager 가 iPhone 과 Watch 사이에서 다음을 동기화합니다.

타이머 시작
타이머 종료
타이머 일시정지/재개
설정 변경

11.3 알림

Watch 에서도 종료 시점에 햅틱과 알림이 발생합니다. 진동 패턴과 알림음은 iPhone 의 설정을 따릅니다.


12. 알림음 및 진동

12.1 종류 (RingMode)

다음 모드 중 하나를 선택할 수 있습니다.

silent: 소리, 진동 모두 없음
vibrate: 진동만
sound: 시스템 기본 알림음
both: 소리와 진동 모두

12.2 적용 범위

UNNotificationContent.sound 에 매핑되어 백그라운드 알림에도 동일하게 적용됩니다.


13. 사용자 정의 메시지

13.1 동작

타이머 종료 시 표시될 토스트 메시지를 사용자가 직접 입력할 수 있습니다. 템플릿별로 다른 메시지를 저장할 수 있습니다.

13.2 기본값

메시지가 비어 있으면 시간 기반으로 자동 생성됩니다. 예: "10 분 종료", "1 시간 30 분 종료".


14. 테마 및 커스터마이징

14.1 색상 모드

라이트, 다크, 시스템 자동 중에서 선택할 수 있습니다.

14.2 액센트 색상

10 가지 색상 중에서 앱 전체의 액센트 색상을 선택할 수 있습니다. 변경 즉시 모든 화면의 강조색이 갱신됩니다.

14.3 라벨 색상

타이머 템플릿마다 다른 라벨 색상을 지정할 수 있어 시각적으로 구분이 가능합니다.


15. 다국어 지원

15.1 지원 언어

한국어, 영어, 일본어를 지원하며 Localizable.xcstrings 에 추가 언어를 쉽게 확장할 수 있습니다. 배포 전 scripts/check_localization.py 가 미번역·사문화 키를 게이트한다.

15.2 시간 표시

분, 초 단위 표기는 각 언어 관습에 맞게 표시됩니다.


16. 리뷰 요청

16.1 자동 요청

LeeoKit 만족도 게이트(.leeoSatisfactionCheck)가 단독 담당합니다. 조건(실행 3회·설치 2일·유의미 이벤트 3회, 버전당 1회)이 맞으면 "즐겁게 쓰고 계신가요?"를 먼저 묻고, 만족 시에만 시스템 리뷰 요청, 불만족 시 피드백 화면으로 연결됩니다.

16.2 빈도 제한

만족도 게이트의 쿨다운은 120일이며 버전당 최대 1회만 노출됩니다.

16.3 수동 요청

설정 화면의 Rate this app 버튼으로 사용자가 직접 App Store 리뷰 페이지로 이동할 수 있습니다.


17. 데이터 모델

17.1 영속화 저장소

SwiftData 의 ModelContainer 에 다음 모델이 저장됩니다.

Timer: 타이머 템플릿
TimerRecord: 타이머 사용 기록

17.2 공유 데이터

App Group UserDefaults (group.leeo.toki) 에 다음을 저장하여 iOS, Watch, Widget 이 공유합니다.

현재 실행 중인 타이머 상태
설정값 (테마, 액센트 색상, 알림 모드 등)


18. 분석 (익명·비추적, 외부 SDK 없음)

AnalyticsManager 는 이벤트 추상화 계층이며, 전송 백엔드로 프라이버시 중심의
외부 분석 SDK를 쓰지 않습니다. Firebase 는 2026-07, TelemetryDeck 은 2026-08 에 제거했고, 익명 사용 통계는 CloudKit 허브(FeedbackHub)로만 모읍니다.
AnalyticsManager.telemetryDeckAppID 가 비어 있으면 어떤 데이터도 외부로 전송되지 않고
DEBUG 콘솔 로깅만 수행합니다. App ID 는 dashboard.telemetrydeck.com 에서 발급 후
해당 상수에 넣으면 활성화됩니다. 개인 식별 정보는 수집하지 않습니다.

18.1 추적 이벤트

타이머 라이프사이클: 시작, 완료, 취소
프리미엄 사용: premium_feature_used (각 사용 시), premium_trial_exhausted (페이월 트리거 시)
페이월: 노출, 닫힘, 5 번 더 클릭, 결제 시도/성공/실패/복원
리뷰: 요청 발송, 완료
기타: 발표 모드 진입, Watch 동기화 사용

18.2 개인정보

NSPrivacyTracking false. 사용자 식별이나 광고 추적에 데이터를 사용하지 않습니다. PrivacyInfo.xcprivacy 에 모든 수집 항목이 명시되어 있습니다.


19. 빌드 및 배포

19.1 버전 관리

Config/Version.xcconfig 에서 모든 타겟의 MARKETING_VERSION 과 CURRENT_PROJECT_VERSION 을 통합 관리합니다(프로젝트 레벨 baseConfiguration, 타겟 하드코딩 금지). scripts/update_version.sh 로 자동 업데이트 가능합니다.

19.2 타겟

Rereminder: iOS 메인 앱
RereminderWatch: Apple Watch 앱
RereminderAlarm: 위젯 및 Live Activity 확장
RereminderMenuBar: Mac Catalyst 메뉴바 (현재 Catalyst 지원 해제로 비활성)
RereminderTests: 유닛 테스트

19.3 의존성

외부 의존성은 LeeoKit 2.9.0(원격 SPM, github.com/M1zz/LeeoKit — StoreKit2 엔진·CloudKit 피드백 허브·사용 통계·리뷰 게이트·원격 킬스위치·MetricKit 크래시 진단) 하나뿐입니다. Firebase·TelemetryDeck 등 외부 분석 SDK 는 사용하지 않습니다.
