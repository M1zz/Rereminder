Rereminder 2.0.4

한국어

다이얼 아래에 템플릿 퀵 바가 생겼습니다. 최근에 쓴 템플릿 칩을 탭하면 설정이 바로 다이얼에 반영되고, 설정을 바꾸면 저장 버튼이 나타나 그 자리에서 새 템플릿으로 저장할 수 있습니다.

앱을 다시 열어도 마지막에 사용한 타이머 설정이 다이얼에 그대로 복원됩니다. 매번 같은 시간을 다시 맞출 필요가 없습니다.

앱 안에서 바로 의견과 버그를 보낼 수 있게 되었습니다. 설정에서 피드백을 남기면 개발자에게 바로 전달됩니다.

여러 기기에서 Rereminder를 어떻게 쓰는지 알려주는 안내 화면이 추가되었습니다. iPhone, Apple Watch, Mac, 위젯에서 각각 무엇을 할 수 있는지 한 곳에서 확인할 수 있습니다.

발표 모드 화면이 더 깔끔해졌습니다. 구간 리스트를 카드형으로 다시 만들어 이름과 길이, 시간 범위를 한눈에 읽을 수 있고, 구간과 겹치던 알림 프리셋 칩은 발표 모드에서 감췄습니다.

예비 알림 칩 크기를 줄여 글씨는 그대로 유지하면서 화면 공간을 넓혔습니다.

외부 분석 도구(Firebase, Google Analytics)를 완전히 제거했습니다. 이제 사용 기록이 외부로 전송되지 않습니다.

기존에 앱을 사용해 주신 분들께는 쓰고 계시던 기능을 계속 무료로 이용할 수 있다는 안내를 드립니다.

설정 화면에서 항목을 눌러도 반응하지 않던 문제 등 자잘한 버그를 수정했습니다.


English

A new template quick bar sits right below the dial. Tap a recent template chip to load its settings instantly, and when you change the dial, a save button appears so you can store it as a template on the spot.

Your last used timer settings are now restored when you reopen the app — no need to dial in the same time again every session.

You can now send feedback and report bugs from inside the app. Leave a note in Settings and it goes straight to the developer.

A new guide shows how to use Rereminder across your devices, covering what iPhone, Apple Watch, Mac, and widgets can each do in one place.

Presentation Mode looks cleaner. The section list has been rebuilt as cards so you can read the name, length, and time range at a glance, and the alert preset chips that overlapped with sections are now hidden in Presentation Mode.

Pre-alert chips are more compact, freeing up screen space while keeping the text size unchanged.

External analytics (Firebase, Google Analytics) have been removed entirely. Your usage data is no longer sent anywhere.

If you have been using the app already, you will see a note confirming that the features you have been using stay free.

Fixed minor bugs, including rows in Settings not responding to taps.


日本語

ダイヤルの下にテンプレートのクイックバーが追加されました。最近使ったテンプレートのチップをタップすると設定がすぐダイヤルに反映され、設定を変更すると保存ボタンが現れてその場で新しいテンプレートとして保存できます。

アプリを開き直しても、最後に使ったタイマー設定がダイヤルにそのまま復元されます。毎回同じ時間を設定し直す必要はありません。

アプリ内から直接ご意見や不具合を送れるようになりました。設定からフィードバックを送ると開発者に直接届きます。

複数のデバイスでRereminderをどう使えるかを紹介するガイド画面を追加しました。iPhone、Apple Watch、Mac、ウィジェットでそれぞれ何ができるかを一か所で確認できます。

プレゼンモードの画面がすっきりしました。セクション一覧をカード型に作り直し、名前・長さ・時間範囲がひと目で読めるようになり、セクションと重複していた通知プリセットのチップはプレゼンモードでは非表示になりました。

事前通知のチップを小さくし、文字サイズはそのままに画面のスペースを広げました。

外部の分析ツール(Firebase、Google Analytics)を完全に削除しました。利用状況が外部に送信されることはなくなりました。

これまでアプリをご利用いただいている方には、お使いの機能を引き続き無料でご利用いただける旨のご案内を表示します。

設定画面の項目をタップしても反応しない問題など、細かな不具合を修正しました。
