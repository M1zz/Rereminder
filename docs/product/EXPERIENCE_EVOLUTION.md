# 쓴 만큼 자라는 앱 — 사용자 경험에 따른 진화

두번알림은 처음부터 모든 것을 보여 주지 않는다. **타이머를 끝까지 마친 횟수**와 **써 온 날수**에 따라
화면과 말이 한 겹씩 늘어난다. 이 문서는 그 모양을 한 장에 모은다. 숫자는 코드가 원본이다(아래 "근거").

## 한 줄 원칙

- 처음 연 사람이 알아야 할 것은 하나다 — "끝나기 전에 미리 알려 준다".
- 나머지는 **필요해질 때쯤** 나타난다. 시간이 아니라 사용(완주)이 문을 연다.
- **한 번 드러난 것은 저절로 감추지 않는다.** 감추는 것은 사람이 고를 때뿐이다.
- **이미 쓰던 사람의 기능은 줄지 않는다.** 이 진화는 새로 설치한 사람의 화면에만 적용된다.
- 안내는 한 번에 하나다. 앱을 열자마자 두 개가 뜨면 둘 다 읽히지 않는다.

## 1. 화면이 자라는 길 (새로 설치한 사람)

`BlankStart.Stage` — 완주 횟수로 정한다. 뒤 단계는 앞 단계를 모두 포함한다.

| 완주 | 단계 | 화면에 새로 생기는 것 | 그 순간 건네는 것 |
|---|---|---|---|
| 0 | 다이얼 | 원, 시작 버튼, 설정, 할 일 한 줄("종을 끌어 언제 들을지 고르고 시작") | 그림 소개 → 해 보기 → 빈 원이 차오르는 그림 |
| 1 | 알림 | 원 아래 알림 문장과 `+ 알림 추가` | 수업 "알림을 여러 개" |
| 2 | 저장 | (🔖 는 처음부터 있다) | 수업 "저장한 설정" |
| 3 | 세션 | 하단 모드 전환(타이머 / 세션 모드) | 토스트 "세션 모드가 아래 막대에 생겼어요" |
| 4 | 세션 | — | 수업 "오버타임" |
| 5+ | 전부 | 기기 연결 칩, 기기 질문(워치·맥), 기능 팁 | — |

- 수업은 완주한 뒤 타이머를 닫는 순간에 하나만 뜬다. 다른 안내에 양보해서 놓치면 다음 완주에 온다.
- 세션 모드 수업은 처음 들어갈 때 배운다(필요한 사람만 쓰는 기능이라 먼저 띄우지 않는다).
- 지름길: 설정 ▸ 모양 ▸ **모든 기능 보기** — 세션 모드가 오늘 당장 필요한 발표자의 길.
- 수업은 설정 ▸ 이 앱 활용법 보기에서 언제든 다시 본다.

### 이미 쓰던 사람

- 처음부터 전부 보인다. 업데이트 뒤 첫 완주를 닫을 때 **"너무 복잡하지 않나요?"** 를 한 번 묻는다.
- "단순하게"를 고르면 저장까지 보이고, 세션 모드를 써 본 사람은 모드 전환도 남는다.

## 2. 앱이 먼저 알아채는 것 (패턴)

사용이 쌓이면 앱이 사람 대신 결심해 준다. 모두 상한이 있고 다른 안내에 양보한다.

| 언제 | 무엇 | 상한 |
|---|---|---|
| 같은 설정을 **서로 다른 날 2일** 이상 | "이 설정을 기억해 둘까요?" | 한 설정에 한 번, 전체 3회(무료 1회) |
| 같은 요일·비슷한 시각(±1시간)에 2일 이상 | 그 시간에 열면 "늘 이맘때 하시던 거네요" → 다이얼에 올림 | 2회 |
| 세션 모드로 끝까지 마친 직후 | "다음 자리는 언제인가요?" → 전날 19시 알림, 그날 열면 설정을 올림 | 3회, 거절하면 완주 5회 유예 |

- 주 단위로 되풀이하는 사람은 위 두 줄이, 분기마다 발표하는 사람은 세 번째 줄이 잡는다.

## 3. 무료에서 결제까지 (돈의 문턱)

`FreeUse` — **기간이 아니라 쓴 만큼으로** 끝나는 무료 사용이다("체험"이라 부르지 않는다).

1. **문턱 전**: 모든 기능이 열려 있고 앱이 먼저 Pro 를 꺼내지 않는다.
2. **문턱**: 완주한 **서로 다른 날 14일** 또는 **세션 완주 5회**. 그때 처음으로 한 번 묻는다.
   날수로 세는 이유 — 횟수로 세면 하루 네 번 도는 포모도로가 먼저 닿고, 주 3회 수업하는 강사(돈을 낼 사람)가 가장 늦게 닿는다.
3. **문턱 뒤 무료**: 마지막 설정 복원·저장한 설정 불러오기·오버타임은 계속 무료. 새 저장은 3개까지,
   기록은 문턱 전 것 + 최근 30일, 세션 모드는 남은 횟수.
4. **결제**: 기억(Plus) → Pro, 칸마다 연 구독과 평생. 페이월은 들어온 자리의 칸을 앞에 세운다.
5. **구독 6개월째**: 갱신 7일 전에 "평생으로 바꾸기"를 한 번 건넨다.

- Pro 언급은 설치당 예산 하나로 센다(`ProMention`): 통틀어 3번, 자리마다 1번, 3일 간격, 알아들으면 멈춤.
- 이미 누리던 것은 문턱이 깎지 않는다. 결제자·평생 무료·창단 후원자는 무료 기간과 무관하다.

## 4. 관계가 깊어지는 길 (말 걸기)

| 언제 | 무엇 |
|---|---|
| 5번째 실행, 이후 20번 간격 | 의견 요청(다시 보지 않기 = 6개월 쉼) |
| 실행 3번 · 설치 2일 · 의미 있는 일 3번 | 만족도 확인 → 좋으면 리뷰, 아니면 의견 (의견 요청은 이것에 양보) |
| 단계 "전부" + 타이머를 걸 때 | "워치 있으세요?" → 하루 뒤 "맥 있으세요?" — 없다고 하면 다시 꺼내지 않음 |
| 이미 Pro 이고 끝까지 마쳤을 때, 드물게 | 팁 부탁 한 줄 |
| 업데이트 뒤 처음 | 새로 생긴 것 한 번 |

## 한눈에

```
설치 ─ 그림·해 보기 ─ 다이얼 하나
  └ 완주 1  알림 더하기
     └ 완주 2  저장 수업 (🔖 는 처음부터)
        └ 완주 3  세션 모드
           └ 완주 4  오버타임
              └ 완주 5  전부 · 기기 질문 · 팁
                 ├ 2일 반복   → 기억해 둘까요 / 늘 이맘때
                 ├ 세션 완주  → 다음 자리 예약
                 └ 14일 · 세션 5회 → 처음으로 Pro 를 묻는다
                       └ 결제 → 6개월째 평생으로
```
