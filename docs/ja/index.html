標準のタイマーに
不満はありませんか？

こうした不満から、多くの人がもっと良いタイマーを探しています。

途中で知らせてくれない

✕ 標準のタイマーは終了時にしか鳴りません。カウントダウンの途中で通知を受け取る方法がありません。
✓ Rereminder は好きなタイミングで知らせます。10分前、5分前、1分前。決めるのはあなたです。

画面が消えてしまう

✕ タイマーの途中で画面が暗くなり、残り時間が見えなくなります。
✓ タイマー中は画面を点灯したまま。さらにロック画面と Dynamic Island にライブアクティビティを表示します。

広告とサブスクリプション

✕ 多くのタイマーアプリは広告だらけか、基本機能に年額6ドルを請求します。
✓ 広告はゼロ。無料で使えます。Pro へのアップグレードは買い切りで、サブスクリプションは一切ありません。

決まりきったタイマー

✕ ポモドーロは25分と5分に縛られます。インターバルタイマーはセットごとに時間を変えられません。
✓ 好きな長さに、好きな事前アラートの組み合わせを。テンプレートとして保存すれば、ワンタップで開始できます。

履歴が散らかる

✕ iOS 17 以降は使ったタイマーがすべて残り、リストがすぐに手に負えなくなります。
✓ お気に入り付きのすっきりしたテンプレート。本当に使うものだけを残せます。

ゼロで止まってしまう

✕ 時間が来たらそれで終わり。どれだけ超過したかを知る方法がありません。
✓ 超過カウンターは 00:00 を過ぎても動き続け、+01:23 のように正確に表示します。

すべての機能は、時間より一歩先を行くために作られています。

🔔

事前アラート

タイマーが終わる10分前、5分前、1分前に通知。タイミングはあなたが決めます。

⏱️

超過時間の記録

タイマーはゼロで止まりません。+MM:SS のカウンターで、どれだけ超過したかが正確にわかります。

🏝️

ライブアクティビティ

Dynamic Island とロック画面にタイマーを表示。いつでも見えて、邪魔になりません。

⌚

Apple Watch

手首からタイマーを操作。開始、一時停止、アラートまで、すべて同期されます。

💾

テンプレート

よく使うタイマー設定を保存。25分の集中時間も1時間の会議も、ワンタップで開始できます。

🎨

テーマ

アクセントカラーを選べます。スタイルに合わせた10種類の美しいプリセット。

3回タップするだけで安心

1

時間を決める

円をドラッグするか、クイックプリセットをタップ。5分、10分、または自由に。

2

事前アラートを選ぶ

欲しいアラートをタップ。「5分前」「1分前」など、お好みで。

3

開始して、あとはおまかせ

大事なことに集中してください。時間になったら Rereminder が肩をたたきます。
