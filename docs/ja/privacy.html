プライバシーポリシー

Rereminder は Hyunho Lee が開発しています。このページでは、何があなたの iPhone の外に出て、何が出ないのかを正確に説明します。

最終更新日：2026年9月9日 · 対象アプリバージョン 2.2.6

要約

あなたが書いたものはすべて iPhone の中に残ります。タイマー名、アラートメッセージ、区間のタイトル、プレゼンテーションの原稿、履歴 — どれもどこにも送信されることはありません。

アプリは匿名の数値を私に送信します。「開始したタイマーの数」「最後まで動いたタイマーの数」といった回数で、あなたとは無関係なランダムな ID に紐づいています。何を直すかはこれをもとに決めています。詳しくは以下に記載しています。

広告も、トラッカーも、サードパーティの分析 SDK もありません。何かを販売したり、誰かと共有したりすることはありません。

デバイスに残るもの

以下はデバイス内に保存され、私に送信されることはありません。

  • タイマーの設定 — 長さ、各アラートを置いた位置、カスタマイズしたアラートメッセージ。
  • テンプレート — 保存した設定とその名前。
  • セッションの内容 — 区間名と、区間ごとに書いた原稿やメモ。
  • 履歴 — 実行したセッションの記録。
  • 環境設定 — テーマカラー、サウンドと振動のモード、持っているとアプリに伝えたデバイス。
  • 購入状況 — Rereminder Pro を所有しているかどうか。iOS のキーチェーンに保存されます。

アプリを削除すると、これらはすべて削除されます。

アプリが私に送信するもの

すべて私が所有する CloudKit データベース（コンテナ iCloud.com.Ysoup.FeedbackHub）に送られます。ほかのサーバーはなく、ほかの企業がこれを受け取ることもありません。

1. 匿名の利用回数

インストールごとに1件の記録で、更新は多くても1日2回です。内容は次のとおりです。

  • 初回起動時にアプリが自分で生成するランダムな ID。これはあなたの Apple アカウントでもデバイスの識別子でもなく、あなたに関する何とも結びついていません。アプリを削除すると ID も消え、再インストールすると、以前とつながりのない新しい ID が作られます。
  • アプリのバージョン、プラットフォーム（iPhone / Watch / Mac）、OS のバージョン、言語設定。
  • 回数、そして回数だけ — 開始・完了・キャンセルしたタイマーの数、管理した合計時間（分）、一般的なタイマーのアラート数、保存・使用したテンプレートの数、セッションモードを使ったことがあるか、ウォッチを使ったことがあるか、インストールからの日数、アプリが最後に使われた時期。
  • はい/いいえのフラグ2つ：Pro を購入したかどうか、通知の許可があるかどうか。

2. 匿名のイベント

アプリが開かれた、タイマーが開始された、購入画面が表示された — といった注目すべきことが起きると、アプリはそのイベントの名前を、アプリのバージョン、プラットフォーム、同じランダムな ID、タイムスタンプとともに記録します。各イベント名は多くても6時間に1回しか記録されないため、これが示すのは何かが起きるかどうかであり、その頻度ではありません。

3. あなたが送ることを選んだフィードバック

フィードバックを送信を開いて送信ボタンを押したときだけです。その記録には次のものが含まれます。

  • あなたのメッセージと、選んだカテゴリ。
  • 名前と返信先メールアドレス — どちらも任意で、初期状態では空欄です。返事がほしい場合にだけ入力してください。あなたへの返信にのみ使い、それ以外には使いません。
  • デバイス情報1行 — アプリのバージョン、デバイスの種類、OS のバージョン。例：App 2.2.6 | iPhone | iOS 26.1。これはデバイスの種類であり、どのデバイスかではありません。あなた固有の情報は含まれていません。送信前に、フォームでこの1行がそのまま表示されます。
  • 言語設定（例：ko_KR）とプラットフォーム。

送信を押さない限り、その画面から何も出ていきません。「アプリを楽しんでいますか？」の表示で 👍 をタップすると App Store のレビュー画面が開くだけで、私には何も送られません。👎 はこの同じフィードバックフォームを開くだけです。

4. クラッシュとフリーズのレポート

Apple の MetricKit を通じて収集されます。MetricKit は OS レベルでクラッシュとパフォーマンスのデータを集計します。これにはスタックトレースとタイミングが含まれますが、タイマーの内容が含まれることはありません。

ひとつ明記しておくこと：デバイスが上記のいずれかを CloudKit に書き込むとき、Apple はその記録に、アプリごとの不透明な iCloud 識別子を付けます。これは Apple が生成するもので、アプリごとに異なり、あなたのメールアドレスではありません。私はこれを使ってあなたに連絡したり、ほかの場所であなたを調べたりすることはできません。これは CloudKit の仕組み上生じるもので、アプリが意図的に収集しているものではありません。

どんな場合でも送信されないもの

  • タイマー名、アラートメッセージ、区間のタイトル、プレゼンテーションの原稿 — あなたが入力したあらゆるテキスト。
  • あなたの名前やメールアドレス — ただし、上記のフィードバックフォームにある任意の2項目は除きます。これはあなた自身が入力するもので、空欄のままにできます。
  • 広告識別子（IDFA）、デバイスのベンダー識別子（IDFV）、その他のデバイスフィンガープリント。
  • 位置情報、連絡先、写真、カレンダー、ヘルスケアデータ、マイク。

あなた自身のデバイス間の同期

iPhone、Apple Watch、Mac はタイマーの状態をそろえます。これはあなた自身の iCloud アカウントと Apple の WatchConnectivity で動作し、データは私を経由せず、あなたの iCloud を通じてデバイスからデバイスへ移動します。私はその内容を一切読めません。含まれるのは、動作中のタイマーの状態と名前、そしてアプリの接続状態に表示されるデバイス名です。

iCloud Drive をオフにするとこの同期は止まり、アプリは各デバイスで単独で動き続けます。

第三者と支払い

Rereminder はサードパーティの分析、広告、トラッキングサービスを一切組み込んでいません。データを販売、貸与、またはほかの企業と共有することはありません。

Rereminder Pro はすべて Apple が処理する買い切りの購入です。私があなたの支払い情報を見ることはなく、わかるのは購入があるかどうかだけです。

通知

すべてのアラートは、デバイス上でスケジュールされるローカル通知です。プッシュサーバーはなく、通知の内容が私に届くことはありません。

保存期間と停止方法

  • アプリを削除すると、すべての収集がただちに止まり、デバイスに保存されたすべてのものとともにランダムな ID も削除されます。
  • 匿名の利用記録は、何を作るかを決めるのに役立つ間は保持し、役立たなくなったら削除します。あなたにたどり着く識別子を含まないため、ご依頼を受けても「あなたの」記録を特定する方法がありません。これは、この記録であなたを特定できないのと同じ理由です。
  • 送信したフィードバックは別です — あなたが書いたものなので、私は見つけられます。メールをいただければ削除します。
  • 利用回数の収集とクラッシュレポートは、全員分を遠隔で停止できます。価値がなくなったと判断すれば、そうします。

子どものプライバシー

Rereminder は、子どもを含め、誰からも個人データを意図的に収集しません。アカウントは不要で、個人情報を求めることもなく、ソーシャル機能、チャット、ユーザー間のコンテンツもありません。

このポリシーの変更

アプリが収集するものが変われば、このページもそれに合わせて変わり、冒頭の日付が更新されます。重要な変更は、その変更を行うバージョンのリリースノートにも記載します。
